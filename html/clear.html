Estudo da propriedade Clear

1. Sem utilizar Clear

Float Left
Float Left

Observe que este texto tenta ocupar o espaço ao lado das caixas porque elas estão utilizando float. Isso acontece porque ainda não utilizamos a propriedade clear.

2. Utilizando clear: both

Float Left
Float Left

Agora este parágrafo começa abaixo das duas caixas. O clear: both impede que ele fique ao lado dos elementos flutuantes.

3. clear: right

Float Right

Como utilizamos clear: right, este texto inicia abaixo do elemento flutuando à direita.

4. clear: left

Float Left

Este texto somente ignora elementos flutuando à esquerda.

5. Limpando o Container

Box 1
Box 2
Box 3

Sem este elemento de limpeza, a borda do container praticamente desapareceria, pois todos os filhos estão utilizando float.
