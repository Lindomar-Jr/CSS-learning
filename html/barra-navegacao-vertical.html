Barra de Navegação Vertical

O que é uma sidebar?

É um menu lateral utilizado para navegação entre páginas ou seções de uma aplicação.

Por que usar display: block?

Sem display: block, apenas o texto do link seria clicável. Com ele, toda a linha do menu torna-se uma área clicável.

Por que usar position: fixed?

O menu permanece visível durante a rolagem da página, melhorando a navegação em sistemas com muito conteúdo.

Hover e experiência do usuário

O efeito hover fornece feedback visual imediato, indicando que o item pode ser clicado.
