Barra de Navegação Horizontal

Este exemplo demonstra como criar uma barra de navegação horizontal utilizando apenas HTML e CSS.

O menu foi construído utilizando uma lista não ordenada (ul), onde cada item (li) contém um link (a).

Com a propriedade display: flex, os itens passam a ficar lado a lado, formando um menu horizontal.

Em telas pequenas, a Media Query altera a direção do Flexbox para coluna, tornando o menu mais adequado para dispositivos móveis.
